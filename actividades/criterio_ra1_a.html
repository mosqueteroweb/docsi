Actividades de evaluación · RA1

1. Test de Autoevaluación

Responde las 5 preguntas. La solución correcta y su justificación aparecen al final de la sección.

1

¿Cuál de los siguientes elementos NO es un componente físico interno de un sistema informático?

  • a)Placa base
  • b)Memoria RAM
  • c)Sistema operativo
  • d)Procesador
2

El chipset de la placa base tiene como función principal:

  • a)Ejecutar las instrucciones del programa
  • b)Gestionar la comunicación entre CPU, memoria y periféricos
  • c)Almacenar datos de forma permanente
  • d)Generar la imagen en el monitor
3

La ranura de expansión PCIe x16 se destina habitualmente a:

  • a)Discos de estado sólido M.2
  • b)Tarjetas gráficas
  • c)Módulos de memoria RAM
  • d)Unidades de disco óptico
4

¿Qué conector de alimentación entrega energía directamente al procesador?

  • a)SATA
  • b)Molex
  • c)ATX 12V / EPS
  • d)IDE
5

El bus frontal (FSB) conectaba principalmente:

  • a)CPU y memoria a través del chipset
  • b)Disco duro y tarjeta gráfica
  • c)Red y puertos USB
  • d)Monitor y procesador

Soluciones del test

  1. C) — El sistema operativo es software; placa base, RAM y CPU son hardware físico.
  2. B) — El chipset (northbridge/southbridge o PCH) arbitra el flujo de datos entre los componentes.
  3. B) — La PCIe x16 aporta el mayor ancho de banda y se usa para la GPU.
  4. C) — El conector de 4/8 pines EPS/12V alimenta la CPU.
  5. A) — El FSB unía la CPU con el northbridge y la RAM.

2. Ejemplo Resuelto NO EVALUABLE

Caso práctico resuelto paso a paso para autoaprendizaje.

Inventario de componentes y sus mecanismos de interconexión

Se dispone de un PC de sobremesa. Identifica sus componentes físicos principales y explica cómo se interconectan entre sí.

Resolución paso a paso
1
Placa base: es la placa central que aloja el resto de componentes y proporciona los buses de interconexión (PCIe, DIMM, SATA).
2
CPU: se inserta en el zócalo (socket) y se comunica con la RAM a través del controlador de memoria y el chipset.
3
Memoria RAM: se instala en las ranuras DIMM; el procesador lee/escribe datos de forma volátil y muy rápida.
4
Tarjeta gráfica: ocupa la ranura PCIe x16 y envía la señal de vídeo al monitor.
5
Disco: conectado por SATA (datos) y alimentado por el conector SATA de la fuente; también puede ir en ranura M.2 PCIe.
6
Fuente de alimentación: suministra energía mediante conectores ATX, EPS y SATA a todos los componentes.
Conclusión: Todo componente se conecta a la placa base mediante un bus o ranura normalizado (socket CPU, DIMM, PCIe, SATA); la fuente alimenta cada elemento y el chipset arbitra la comunicación.
