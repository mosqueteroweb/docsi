1. Test de Autoevaluación

Responde las 5 preguntas. La solución correcta y su justificación aparecen al final de la sección.

1

La memoria RAM se caracteriza principalmente por ser:

  • a)No volátil y de muy baja velocidad
  • b)Volátil y de acceso muy rápido
  • c)Solo de lectura
  • d)De almacenamiento permanente en disco
2

¿Cuál de estas memorias es de solo lectura y no volátil?

  • a)DDR4
  • b)SRAM caché
  • c)ROM / EEPROM
  • d)DRAM
3

La memoria caché (SRAM) respecto a la RAM principal (DRAM):

  • a)Es más lenta pero mayor capacidad
  • b)Es más rápida y más cara por bit
  • c)Es no volátil
  • d)Cumple la misma función que el disco duro
4

La memoria virtual utiliza:

  • a)Solo la caché L3
  • b)Espacio en disco (swap) como extensión de la RAM
  • c)Memoria ROM
  • d)La BIOS
5

En la jerarquía de memoria, el orden de mayor a menor velocidad es aproximadamente:

  • a)Disco → RAM → Caché → Registros
  • b)Registros → Caché → RAM → Disco
  • c)RAM → Registros → Caché → Disco
  • d)Caché → Disco → RAM → Registros

Soluciones del test

  1. B) — La RAM es volátil (pierde datos sin energía) y de acceso rápido para la CPU.
  2. C) — La ROM/EEPROM conserva datos sin energía y almacena el firmware (BIOS/UEFI).
  3. B) — La SRAM de caché es mucho más rápida y costosa, ubicada cerca de la CPU.
  4. B) — El sistema operativo usa un archivo de intercambio o partición swap en disco.
  5. B) — Los registros son los más rápidos y el disco el más lento.

2. Ejemplo Resuelto NO EVALUABLE

Caso práctico resuelto paso a paso para autoaprendizaje.

Clasificación de las memorias de un equipo

Un servidor monta 32 GB DDR4, caché L3 de 16 MB, SSD de 1 TB y BIOS en ROM. Clasifica cada memoria y describe su función.

Resolución paso a paso
1
Registros (internos CPU): memoria ultrarápida dentro del procesador; almacenan datos en operación inmediata.
2
Caché L3 (SRAM): memoria volátil muy rápida que reduce la latencia entre CPU y RAM.
3
RAM DDR4 (32 GB, DRAM): volátil, aloja el SO y los programas en ejecución; alta capacidad y velocidad.
4
SSD (almacenamiento masivo): no volátil (flash NAND), guarda el SO, datos y archivos de forma permanente.
5
ROM/BIOS: no volátil de solo lectura/escritura limitada; contiene el firmware de arranque.
Conclusión: Cada nivel cumple una función: registros/caché aceleran el CPU, la RAM ejecuta programas, el SSD/ROM conservan datos de forma permanente. La jerarquía equilibra velocidad, capacidad y coste.

Segundo caso — Caso 2 — Jerarquía de memoria

Ordena de más rápida/menor a más lenta/mayor: registros, caché L1, RAM, disco. Explica que el SO mueve datos del disco a RAM y de RAM a caché/registros según se necesitan. Conclusión: la velocidad de cada nivel define el rendimiento global.
