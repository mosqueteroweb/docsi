1. Test de Autoevaluación

Responde las 5 preguntas. La solución correcta y su justificación aparecen al final de la sección.

1

Un teclado y un ratón son periféricos de:

  • a)Salida
  • b)Almacenamiento
  • c)Entrada
  • d)Comunicación
2

La impresora 3D es un periférico de:

  • a)Entrada
  • b)Salida / fabricación
  • c)Almacenamiento
  • d)Red
3

Para instalar un periférico en Windows, el paso habitual es:

  • a)Formatear el disco
  • b)Conectar y dejar que el SO instale el controlador (driver)
  • c)Desactivar la BIOS
  • d)Eliminar la RAM
4

Un adaptador USB-C a HDMI permite:

  • a)Conectar un disco IDE
  • b)Adaptar la señal de un puerto a un conector distinto
  • c)Aumentar la RAM
  • d)Crear una red inalámbrica
5

Un periférico plug-and-play se caracteriza por:

  • a)Requerir configuración manual de IRQs
  • b)Ser detectado y configurado automáticamente por el SO
  • c)No necesitar energía
  • d)Ser exclusivo de Linux

Soluciones del test

  1. C) — Ambos introducen datos al sistema.
  2. B) — Produce una salida física (objeto).
  3. B) — El SO detecta el dispositivo y carga/instala el driver.
  4. B) — Es un adaptador de interconexión de señales/conectores.
  5. B) — PnP permite detección y configuración automática.

2. Ejemplo Resuelto NO EVALUABLE

Caso práctico resuelto paso a paso para autoaprendizaje.

Instalación y configuración de una impresora de red

Se desea instalar una impresora multifunción en un aula Windows para que la usen 15 alumnos.

Resolución paso a paso
1
1. Clasificación: es un periférico de salida (e impresión) con interfaz de red (Ethernet/Wi-Fi) y también de entrada si tiene escáner.
2
2. Conexión física: se conecta por cable UTP al switch o por Wi-Fi a la WLAN del aula.
3
3. Instalación del driver: en cada PC se añade la impresora por IP (Puertos → TCP/IP) e(instala el controlador del fabricante).
4
4. Configuración: se define como impresora predeterminada y se limitan permisos (colas, cuotas) según el grupo de alumnos.
5
5. Verificación: se imprime una página de prueba desde cada equipo.
Conclusión: Clasificar el periférico, conectarlo, instalar el driver adecuado y verificar la impresión de prueba asegura una configuración correcta y compartible.

Segundo caso — Caso 2 — Configurar una impresora USB

Conecta la impresora, el SO detecta el adaptador y busca el driver. Pasos: instalar driver, fijar como impresora predeterminada, imprimir página de prueba. Conclusión: el periférico queda operativo tras driver + configuración.

4. Actividades adicionales para practicar

Ejercicios para reforzar y autoevaluar el criterio. Material de apoyo: contenido del RA.

1

Actividad adicional 1: Periférico PS/2

Enunciado: ¿Por qué no debes conectar un teclado PS/2 con el equipo encendido?

Resolución: PS/2 no es hot-plug; puede quemar el puerto o la placa.

2

Actividad adicional 2: Adaptador

Enunciado: Conectas un USB-C a un puerto USB-A. ¿Qué elemento interviene?

Resolución: Un adaptador/conversor de conector; el bus sigue siendo USB.
