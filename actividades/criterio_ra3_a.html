Criterio RA3-a: Comparar los sistemas de archivos libres y propietarios

RA3-a

Se evalúa la capacidad de diferenciar ext4, NTFS y FAT, y de elegir el adecuado según el sistema operativo y el uso.

Test de conocimientos

¿Qué sistema de archivos es nativo y estándar en Linux?

  • FAT32
  • NTFS
  • ext4
  • exFAT

Solución: c.

¿Cuál soporta permisos ACL y cifrado de forma nativa en Windows?

  • FAT32
  • NTFS
  • ext2
  • ext3

Solución: b.

Limitación principal de FAT32:

  • No soporta carpetas
  • Archivos de máximo 4 GB
  • Solo en Linux
  • Requiere cifrado

Solución: b.

El journaling sirve para:

  • Aumentar el tamaño del disco
  • Recuperar el sistema tras un fallo
  • Comprimir archivos
  • Borrar permisos

Solución: b.

Para máxima compatibilidad entre Windows y Linux en un USB, se suele usar:

  • ext4
  • NTFS
  • FAT32 o exFAT
  • ZFS

Solución: c.

Ejemplo resuelto (no evaluable)

Situación: tienes un disco SSD de 1 TB en un equipo con doble arranque (Windows + Linux).

Solución propuesta: se crea una partición NTFS de 500 GB para Windows (arranque y programas), una partición ext4 de 400 GB para Linux (raíz /) y una partición exFAT de 100 GB compartida para intercambiar archivos entre ambos sistemas sin problemas de permisos.

Así cada SO usa su sistema nativo y la partición exFAT actúa como zona neutra de intercambio.

4. Actividades adicionales para practicar

Ejercicios para reforzar y autoevaluar el criterio. Material de apoyo: contenido del RA.

1

Actividad adicional 1: ¿Qué es un SF?

Enunciado: Diferencia datos y metadatos en un archivo.

Resolución: Datos=contenido; metadatos=fecha/permisos/tamaño que guarda el SF.

2

Actividad adicional 2: FAT32 vs NTFS

Enunciado: ¿Qué ventaja tiene NTFS sobre FAT32?

Resolución: Journaling y permisos; FAT32 simple y sin permisos.
