Criterio RA3-b: Identificar la estructura de directorios en SO libres y propietarios

RA3-b

Se evalúa el conocimiento del árbol de directorios en Linux (FHS) y Windows, y la distinción entre rutas absolutas y relativas.

Test de conocimientos

En Linux, el directorio personal del usuario se encuentra en:

  • /usr
  • /home/usuario
  • /etc
  • C:\Users

Solución: b.

En Windows, la carpeta de usuarios es:

  • /home
  • C:\Users
  • /var
  • D:\

Solución: b.

Una ruta absoluta en Linux siempre comienza por:

  • ~
  • ./
  • /
  • ..

Solución: c.

El símbolo .. en una ruta representa:

  • El directorio actual
  • El directorio padre
  • La raíz
  • El usuario

Solución: b.

¿En qué directorio de Linux se guardan archivos de configuración del sistema?

  • /var
  • /home
  • /etc
  • /tmp

Solución: c.

Ejemplo resuelto (no evaluable)

Situación: desde /home/usuario/docs queremos listar el contenido de /var/log usando rutas relativas y absolutas.

Solución:

# Ruta absoluta
ls /var/log
# Ruta relativa (subimos a /home/usuario, luego a /, luego var/log)
ls ../../var/log

Ambas comandan el mismo resultado; la absoluta es menos propensa a errores.

Actividad evaluable

Dibuja (en texto o con un esquema) el árbol de directorios típico de Linux mostrando al menos /, /home, /etc, /var y /usr, e indica el contenido de cada uno. Luego escribe 3 comandos usando rutas relativas para: crear una carpeta dentro de tu directorio actual, subir un nivel y listar su contenido, y copiar un archivo de la carpeta padre a la actual.
