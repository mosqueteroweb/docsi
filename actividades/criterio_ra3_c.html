Criterio RA3-c: Localizar información del sistema (hardware, procesos y configuración)

RA3-c

Se evalúa la capacidad de obtener datos del equipo: componentes, procesos en ejecución y archivos de configuración, usando comandos y herramientas gráficas.

Test de conocimientos

¿Qué comando muestra los procesos en ejecución en Linux?

  • ls
  • ps
  • cp
  • df

Solución: b.

Para ver el uso de memoria en tiempo real se usa:

  • top
  • find
  • grep
  • mount

Solución: a.

El archivo /etc/fstab sirve para:

  • Configurar el arranque de particiones
  • Guardar contraseñas
  • Listar procesos
  • Definir usuarios

Solución: a.

En Windows, la información de hardware se consulta con:

  • msinfo32
  • notepad
  • cmd
  • explorer

Solución: a.

¿Qué utilidad gráfica de Linux muestra el uso de CPU y disco?

  • Nautilus
  • Monitor del sistema
  • gedit
  • cron

Solución: b.

Ejemplo resuelto (no evaluable)

Situación: un equipo va lento y sospechas que un proceso consume mucha CPU.

Solución: ejecutas top y observas que firefox usa el 90 % de CPU. Con ps aux | grep firefox localizas el PID y, si es necesario, lo terminas con kill 1234. En Windows usarías el Administrador de tareas (Ctrl+Shift+Esc).

top
ps aux | grep firefox
kill 1234

Actividad adicional 1: Buscar por nombre

Enunciado: Comando para hallar 'informe*' desde la raíz en Linux.

Resolución: find / -name 'informe*'.

2

Actividad adicional 2: Buscar por contenido

Enunciado: Comando para buscar 'error' en /var/log.

Resolución: grep -r 'error' /var/log.
