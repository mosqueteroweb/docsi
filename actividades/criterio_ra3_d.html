Criterio RA3-d: Localizar información mediante comandos (find, grep) y herramientas gráficas

RA3-d

Se evalúa el uso de find y grep para localizar archivos y texto, y su equivalente en entornos gráficos.

Test de conocimientos

¿Qué comando busca archivos por nombre?

  • grep
  • find
  • cat
  • echo

Solución: b.

Para buscar el texto "error" en todos los logs recursivamente usamos:

  • find /var -name "error"
  • grep -r "error" /var/log
  • ls error
  • cp error

Solución: b.

La opción -i de grep sirve para:

  • Ignorar mayúsculas/minúsculas
  • Buscar en archivos
  • Invertir la búsqueda
  • Contar líneas

Solución: a.

¿Qué herramienta gráfica de Linux busca archivos por contenido?

  • Catfish
  • gedit
  • top
  • rsync

Solución: a.

Para buscar archivos mayores de 50 MB con find usamos:

  • find / -name "*.big"
  • find / -type f -size +50M
  • find / -size 50
  • grep 50M

Solución: b.

Ejemplo resuelto (no evaluable)

Situación: necesitas encontrar en qué archivos de configuración aparece la palabra "Listen" del servidor web.

Solución: combinas find y grep para recorrer /etc y buscar el patrón:

find /etc -type f -exec grep -l "Listen" {} \;

Esto lista los archivos que contienen la cadena. En Windows usarías el buscador de Configuración o el Explorador con la opción "Contenido".

Actividad evaluable

Escribe 4 comandos (con una breve explicación de cada uno) que resuelvan: (1) encontrar todos los archivos .conf en /etc, (2) buscar "WARNING" en /var/log ignorando mayúsculas, (3) contar cuántas veces aparece "root" en /etc/passwd, y (4) localizar archivos vacíos en tu directorio personal. Indica además qué herramienta gráfica usarías en Windows para la búsqueda (2).
