Criterio RA3-g: Planificar y automatizar tareas

RA3-g

Se evalúa el uso de cron, systemd timers y el Programador de tareas de Windows para ejecutar trabajos de forma periódica.

Test de conocimientos

¿Qué comando edita la tabla de tareas de cron?

  • crontab -e
  • cron edit
  • systemctl edit
  • atq

Solución: a.

En la expresión "30 2 * * 1", el "1" final significa:

  • Día del mes
  • Mes
  • Día de la semana (lunes)
  • Hora

Solución: c.

El programador de tareas de Windows se gestiona con:

  • schtasks
  • crontab
  • systemctl
  • rsync

Solución: a.

¿Cuál es una ventaja de systemd timers sobre cron?

  • Registro de estado y dependencias
  • No necesita root
  • Solo funciona en Windows
  • Es más lento

Solución: a.

Para ejecutar una tarea cada 15 minutos se usa:

  • "0 0 * * *"
  • "*/15 * * * *"
  • "15 * * * *"
  • "* 15 * * *"

Solución: b.

Ejemplo resuelto (no evaluable)

Situación: quieres que cada domingo a las 23:00 se ejecute una limpieza de temporales.

Solución con cron: añades a crontab -e la línea:

0 23 * * 0 rm -rf /tmp/limpieza/*

Solución con systemd: creas limpieza.timer con OnCalendar=Sun *-*-* 23:00:00 y habilitas la unidad. En Windows usarías schtasks /create /sc weekly /d SUN /st 23:00 /tn "Limpieza" /tr "limpiar.bat".

Actividad evaluable

Escribe una entrada de crontab que haga una copia de seguridad de /var/www hacia /backup todos los días a las 03:15, usando rsync. Explica qué significa cada campo de la expresión y redacta también el comando schtasks equivalente para Windows (asumiendo un script backup.bat).
