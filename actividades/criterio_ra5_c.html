Criterio RA5-c: Redes de área local inalámbricas

RA5-c

Se evalúa la capacidad de configurar una WLAN: seleccionar canal, SSID, seguridad WPA2/3 y verificar la asociación de equipos.

Test de conocimientos

El estándar Wi-Fi corresponde a:

  • IEEE 802.3
  • IEEE 802.11
  • IEEE 802.1X
  • IEEE 802.1Q

Solución: b.

WPA3 mejora la seguridad frente a WPA2 mediante:

  • WEP
  • SAE en lugar de PSK
  • HTTP
  • Telnet

Solución: b.

Un punto de acceso (AP) sirve para:

  • Enrutar entre redes
  • Dar cobertura inalámbrica
  • Asignar IP por DHCP sólo
  • Cifrar discos

Solución: b.

La banda de 5 GHz ofrece típicamente:

  • Mayor alcance
  • Mayor velocidad
  • Menor frecuencia
  • Solo 2.4 GHz

Solución: b.

Para asociarse a una WLAN se necesita:

  • El SSID y la clave
  • La dirección MAC del router
  • Un cable
  • El nombre DNS

Solución: a.

Ejemplo resuelto (NO evaluable)

Explica cómo conectar un portátil a una WLAN llamada 'Aula' con WPA2: lista los pasos y los parámetros (SSID, cifrado, clave) y por qué WPA2 es seguro.

Actividad evaluable

Configura (real o simulado) una red Wi-Fi con SSID propio y seguridad WPA2/WPA3; conecta un dispositivo, verifica con ping y documenta el procedimiento y los parámetros.

Rúbrica (sobre 10 puntos)

  • 3 pts — Configuración de SSID y seguridad WPA2/3.
  • 3 pts — Asociación correcta del cliente.
  • 2 pts — Verificación de conectividad.
  • 2 pts — Documentación y buenas prácticas.
