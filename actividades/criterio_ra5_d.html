Criterio RA5-d: Dispositivos de interconexión de redes

RA5-d

Se evalúa la capacidad de interconectar redes mediante switches y routers, y configurar rutas estáticas y dinámicas.

Test de conocimientos

Dispositivo que encamina paquetes entre redes distintas:

  • Hub
  • Switch
  • Router
  • Repetidor

Solución: c.

El enrutamiento estático se caracteriza por:

  • Aprender rutas solo
  • Rutas definidas manualmente
  • Usar OSPF
  • Ser dinámico

Solución: b.

OSPF y RIP son protocolos de:

  • Conmutación
  • Enrutamiento dinámico
  • Cifrado
  • DNS

Solución: b.

Un hub opera en la capa:

  • 1 Física
  • 2 Enlace
  • 3 Red
  • 7 Aplicación

Solución: a.

La función de un switch es:

  • Repetir a todos los puertos
  • Conmutar tramas por MAC
  • Enrutar por IP
  • Traducir nombres

Solución: b.

Ejemplo resuelto (NO evaluable)

Describe cómo un router con dos interfaces (192.168.1.0/24 y 10.0.0.0/24) enruta un paquete de una red a otra usando su tabla de rutas.

Actividad evaluable

Configura una ruta estática en un router (o equipo con ip route) para alcanzar una red remota vía un siguiente salto; verifica con ping y traceroute y documenta.

Rúbrica (sobre 10 puntos)

  • 3 pts — Identificación correcta de dispositivos.
  • 3 pts — Configuración de ruta (estática/dinámica).
  • 2 pts — Verificación (ping/tracert).
  • 2 pts — Documentación de la topología.
