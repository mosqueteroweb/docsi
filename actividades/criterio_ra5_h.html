Test de conocimientos

HTTPS usa para cifrar:

  • TLS
  • HTTP plano
  • FTP
  • Telnet

Solución: a.

IPSec se usa en:

  • VPN/redes
  • USB
  • Ratón
  • Monitor

Solución: a.

SSH cifra:

  • La sesión remota
  • El ratón
  • La impresora
  • El USB

Solución: a.

Telnet es inseguro porque:

  • Va en claro
  • Es lento
  • No existe
  • Es USB

Solución: a.

Un certificado TLS autentica:

  • El servidor/web
  • El ratón
  • La RAM
  • El monitor

Solución: a.

Ejemplo resuelto (NO evaluable)

Compara HTTP (claro) vs HTTPS (TLS): explica por qué un formulario de login debe usar siempre HTTPS.

Actividad evaluable

Configura/verifica que un servicio web use HTTPS (certificado) y documenta la diferencia de seguridad frente a HTTP. Entrega capturas o diagrama.
