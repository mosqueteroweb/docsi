Periféricos. Adaptadores para la conexión de dispositivos.

Los periféricos amplían las capacidades del equipo: entrada (teclado, ratón, escáner), salida (monitor, impresora) y mixtos (discos externos, pantallas táctiles). Se conectan mediante interfaces y adaptadores normalizados.

1. Clasificación

  • Entrada: teclado, ratón, micrófono, cámara, escáner.
  • Salida: monitor, impresora, altavoces.
  • Mixtos: pantalla táctil, unidad externa, tarjeta de red.

2. Interfaces y adaptadores

  • USB: estándar universal (2.0, 3.0/3.2, USB4/Thunderbolt 4). Alimenta y transfiere.
  • PCIe: para tarjetas internas (gráfica, red).
  • HDMI / DisplayPort: vídeo. DisplayPort 2.1 y HDMI 2.1 soportan 4K/8K.
  • Bluetooth: inalámbrico de corto alcance.
  • USB-C / Power Delivery: conector reversible que unifica datos, vídeo y carga.

3. Instalación y configuración

En sistemas modernos, muchos periféricos son plug-and-play: el SO detecta el dispositivo y carga su controlador. La configuración puede requerir ajustar resolución, botones, o instalar software del fabricante. En el criterio RA1-d se evalúa esta tarea.

Ejemplo resuelto en clase

Caso práctico: Conectar un periférico y verificar su adaptador.

  1. Conecta una impresora USB; el SO detecta el adaptador y busca el controlador.
  2. Si es PS/2 (teclado ratón antiguo), usa el conector verde/morado: no es hot-plug, apaga antes.
  3. Verifica en 'Administrador de dispositivos' que el periférico aparece sin errores.
  4. Comprueba que el adaptador (p. ej. USB-C a USB-A) coincide con el puerto físico disponible.

Ampliación de contenido

Para entender lo anterior (puentes conceptuales)

  • El equipo "habla" con el mundo a través de los periféricos. Sin ellos, la CPU sería una caja que calcula en silencio: el teclado es el oído, el monitor los ojos, el disco la memoria externa. Por eso se dividen según el sentido del flujo de datos.
  • Cada interfaz es un "idioma + enchufe". Una interfaz (USB, HDMI, PCIe) define tanto el conector físico como el protocolo eléctrico y lógico. Un adaptador (USB→HDMI) traduce de un idioma a otro cuando el equipo no tiene la salida nativa.
  • Controlador (driver) = traductor de software. El SO no sabe cómo mover el brazo de una impresora concreta; el driver se lo dice. Por eso "plug-and-play" funciona solo cuando el driver está disponible (en el SO o descargable).

Para profundizar en los contenidos actuales

Entrada/salida/mixto es según la dirección del dato. Entrada = del mundo al equipo (teclado); salida = del equipo al mundo (monitor); mixto = ambos (disco externo, pantalla táctil que muestra y recibe pulsos). Una impresora 3D es salida (recibe el modelo), pero un escáner es entrada.

USB: versiones y ancho de banda. USB 2.0 (~480 Mb/s), USB 3.2 Gen1 (5 Gb/s), Gen2 (10 Gb/s), USB4/Thunderbolt 4 (40 Gb/s). Además, USB entrega corriente: carga móviles y alimenta discos sin fuente propia. El conector USB-C es reversible y, con Power Delivery, puede dar 100 W para cargar el portátil.

HDMI vs DisplayPort. Ambos llevan vídeo (y audio). DisplayPort suele usarse en PC y permite encadenar monitores (Daisy Chain, MST); HDMI domina la televisión y consolas. Las versiones 2.1/2.1 admiten 4K/8K a alto refresco. La elección importa para montar varias pantallas o jugar.

PCIe para internos. Las tarjetas internas (gráfica, red, capturadora) usan ranuras PCIe del mismo tema anterior: la gráfica va en la ranura x16 principal. Un adaptador PCIe→M.2 permite añadir discos rápidos a placas viejas.

Bluetooth y el rango corto. Es inalámbrico de baja potencia (ratones, auriculares, teclados). Compite con Wi-Fi para datos, pero está pensado para dispositivos cercanos y bajo consumo; necesita un adaptador (interno o USB) y emparejamiento (pairing) previo.

Revisión didáctica

  • Una pantalla táctil es mixta, no solo salida. Muestra imagen (salida) y recibe toques (entrada). Error típico clasificarla solo como monitor.
  • USB-C es el conector, no la velocidad. Un puerto USB-C puede ser 2.0 lento o USB4 rápido; mirar la versión, no la forma.
  • Adaptador ≠ controlador. El adaptador es hardware que cambia el conector/protocolo; el controlador es el software que lo hace funcionar.
  • Plug-and-play no es mágico. Dependes de que el SO traiga el driver; si no, hay que instalarlo manualmente.
  • HDMI y DisplayPort no son intercambiables sin adaptador. Mismo propósito (vídeo) pero conector y protocolo distintos.

Hilo de aprendizaje sugerido: (1) ¿para qué sirven los periféricos? → (2) clasificar por dirección del dato → (3) interfaces físicas (USB/HDMI/PCIe) → (4) inalámbricos (Bluetooth) → (5) drivers y plug-and-play → (6) instalación y configuración práctica.
