Tipos de sistemas operativos

Existen familias de SO muy distintas según licencia, núcleo y uso. Las más relevantes en FP son Microsoft Windows, las distribuciones GNU/Linux y macOS, además de SO empotrados y móviles.

1. Microsoft Windows

SO propietario de Microsoft, con núcleo híbrido (NT). Dominante en escritorio empresari al y doméstico. Versiones: Windows 10/11, Windows Server. Fuerte compatibilidad con hardware y software comercial.

2. GNU/Linux

Familia de SO libres con núcleo Linux. Se distribuye en distribuciones (Ubuntu, Debian, Fedora, CentOS) que empaquetan el núcleo, herramientas GNU y entorno gráfico. Base de la mayoría de servidores y dispositivos embebidos.

3. macOS y otros

  • macOS: basado en UNIX (Darwin), propiedad de Apple.
  • Android/iOS: SO móviles (Linux y derivado de Darwin respectivamente).
  • SO empotrados (RTOS): para dispositivos con restricciones de tiempo real.
  • SO de red/servidor: optimizados para servicios (Windows Server, servidores Linux).

Ampliación de contenido

Para entender lo anterior (puentes conceptuales)

  • "SO" es la familia; "distribución" es el producto. Linux es el núcleo; Ubuntu/Debian son empaques distintos encima. Como "coche" (concepto) vs "modelo concreto".
  • Libre vs propietario cambia cómo se mantiene. Lo libre (GPL) permite ver y modificar el código y cuenta con comunidad; lo propietario (Windows, macOS) lo controla una empresa y se paga licencia.
  • Núcleo y licencia son independientes. macOS y iOS comparten base UNIX pero distinta licencia; Linux es libre aunque muchas distros se usen en empresas.

Para profundizar en los contenidos actuales

Windows NT (núcleo híbrido). No es monolítico puro ni microkernel puro: combina un modo kernel con subsistemas en modo usuario. Eso explica su compatibilidad (Win32, pero también capas para apps antiguas) y su peso.

Distribuciones GNU/Linux. Todas usan el núcleo Linux + herramientas GNU, pero difieren en gestor de paquetes (apt, dnf, rpm) y filosofía. Ubuntu es fácil para empezar; Debian estable para servidores; Fedora a la vanguardia; CentOS/RHEL para empresas.

macOS y UNIX. Su base Darwin es un sistema tipo UNIX certificado; de ahí su robustez multiusuario y su terminal potente (bash/zsh). Android usa núcleo Linux; iOS usa un derivado de Darwin.

RTOS (tiempo real). En electrodomésticos, médicos o automoción, el SO debe responder en un tiempo garantizado (no "lo antes posible" sino "antes de X ms"). Ahí importa la predictibilidad, no la multitarea general.

Elegir SO = elegir ecosistema. El SO determina qué apps corren, qué formatos abre y cómo se administra. Por eso en un aula se elige según objetivos (servidor Linux, escritorio Windows, creatividad macOS).

Revisión didáctica

  • Linux ≠ una sola marca. Es una familia de distros; decir "voy a instalar Linux" requiere elegir cuál.
  • Distribución no es "el núcleo". La distro añade entorno gráfico, gestor de paquetes y configuración; el núcleo es solo Linux.
  • macOS no es Windows con otra cara. Es UNIX certificado; su funcionamiento interno es distinto y muy potente en línea de comandos.
  • RTOS no es "SO pequeño normal". Tiene restricción de tiempo real que los de escritorio no garantizan.
  • Libre no significa "sin soporte". Hay empresas que dan soporte profesional a Linux (Red Hat, Canonical).

Hilo de aprendizaje sugerido: (1) familias (Windows/Linux/macOS) → (2) qué es una distribución → (3) núcleo híbrido vs Linux vs Darwin → (4) libre vs propietario → (5) móviles y empotrados (RTOS) → (6) cómo elegir SO según uso.
