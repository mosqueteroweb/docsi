Guion de impartición — RA2 | Sistemas Informáticos

Instala sistemas operativos libres y propietarios, aplicando técnicas de virtualización

Cómo usar este guion

Dinámica de clase propuesta: explicar el contenido → mostrar el ejemplo resuelto en clase → proponer el ejercicio para resolver → evaluar con la actividad de evaluación. Este guion enlaza, para cada tema, el contenido teórico y la actividad de evaluación correspondiente.

El módulo suma 120 horas (~6 h/semana). La distribución horaria exacta por RA se definirá en la programación temporal.
