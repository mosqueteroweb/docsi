Resultado de Aprendizaje 1

Evalúa sistemas informáticos, identificando sus componentes y características. Esta página agrupa los contenidos básicos y las actividades de evaluación asociadas a cada criterio.

Contenidos básicos

  • Contenido básico 01: Placas base. Formatos.
  • Contenido básico 02: Estructura y componentes: procesador, memoria interna, interfaces E/S, discos
  • Contenido básico 03: Periféricos. Adaptadores para la conexión de dispositivos.
  • Contenido básico 04: Normas de seguridad y prevención de riesgos laborales.
  • Contenido básico 05: Características de las redes. Ventajas e inconvenientes.
  • Contenido básico 06: Tipos de redes.
  • Contenido básico 07: Componentes de una red informática.
  • Contenido básico 08: Topologías de red.
  • Contenido básico 09: Tipos de cableado. Conectores.
  • Contenido básico 10: Mapa físico y lógico de una red local.

Criterios de evaluación y actividades

  • Criterio a: Reconocimiento de componentes físicos y mecanismos de interconexión.
  • Criterio b: Clasificación de tipos de memorias y sus prestaciones.
  • Criterio c: Verificación del proceso de puesta en marcha de un equipo.
  • Criterio d: Clasificación, instalación y configuración de periféricos.
  • Criterio e: Identificación de tipos de redes y sistemas de comunicación.
  • Criterio f: Identificación de componentes de una red informática.
  • Criterio g: Interpretación de mapas físicos y lógicos de una red.
  • Criterio h: Normas de seguridad y prevención de riesgos laborales.
